# 목차 미리보기

넓은 채팅 화면의 native 목차와 기존 눈금·메시지 이동을 사용한다.
선택한 사용자 메시지는 12px/16px·600의 한 줄 말줄임으로 표시한다.
그 아래에는 에이전트 응답을 11px/18px·400과 `--muted-foreground`로 최대 6줄 표시한다.
카드 최소 높이는 96px이며 기존 최대 높이와 glass 표면은 유지한다.

## 대화 연결

확인한 설치 BB 0.48.1의 목차는 사용자·에이전트 목록을 분리한다.
목차를 실제로 사용할 때 공개 SDK의 `conversationOutline`을 읽고, 사용자 ID별 마지막 에이전트 미리보기를 연결한다.
채팅 진입·전환만으로는 목차를 조회하지 않는다. 같은 조회는 합치고 전환 시 `AbortSignal`로 취소한다.
새 응답·사용자 입력 완료는 목차를 오래된 상태로 표시하며, 사용 중인 목차만 다시 읽는다.
진행 중 변경이 오면 이전 응답을 적용하지 않고 최신 자료를 다시 읽는다.

최근 8개 스레드의 미리보기 텍스트만 메모리에 보관한다. 각 응답은 2,000자,
각 스레드는 256개 항목·32,000자, 전체는 128,000자를 넘지 않는다.
상한은 JavaScript 문자열 길이 기준이며 ID·Map 오버헤드를 포함한 메모리 바이트 수는 아니다.
오래된 항목부터 비우며 화면 DOM이나 React 트리는 이 캐시에 보관하지 않는다.
재방문은 같은 사용자 ID의 캐시를 먼저 표시한 뒤 첫 목차 사용 시 다시 확인하므로,
최신 조회 전에는 직전 방문의 미리보기가 잠깐 표시될 수 있다.

SDK 자료를 기다리거나 해당 항목이 캐시 상한 밖이면 같은 native 목차의 현재 `timelineRows`를 읽는다.
이 경로는 현재 DOM props와 일치하는 React 연결과 사용자 ID가 모두 있어야 한다.
선택한 사용자 뒤부터 다음 사용자 앞까지의 마지막 응답을 쓰며 대화 요약에서 탐색을 멈춘다.
다른 스레드 자료를 사용하거나 문장 일치로 추정하지 않는다. 자료를 확인할 수 없으면 안내를 표시한다.

React DOM 연결은 BB의 공개 SDK 계약이 아니다. BB 갱신 때 재검증해야 한다.
현재 props를 유일하게 확인하지 못하면 이전 트리를 골라 쓰지 않는다.
원래 사용자 버튼과 이동 콜백은 유지하고, 플러그인 소유 응답 span만 추가·제거한다.
목차를 떠나거나 레일·목차가 제거되거나 플러그인이 해제되면 소유 span을 정리한다.

## 포인터 작업

첫 진입은 즉시 처리하고 이후 이동은 한 표시 프레임에 모은다.
눈금의 상대 세로 위치를 재사용하며 레일 교체·내용 변경·높이 변화·스크롤·창 크기 변경 때 다시 읽는다.
너비를 바꾸기 전에 위치를 읽으며, 목록 전체 대신 이전·새 선택 항목만 갱신한다.
실제 클릭은 최신 위치를 읽어 기존 native 이동을 실행한다.
떠남·제거·해제 시 예약된 표시 작업과 크기·스크롤 관찰을 해제한다.
